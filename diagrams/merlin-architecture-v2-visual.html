The EXPRESS Delivery Arc

One agent. Six disciplined phases.

Continuity preserves intent: the same accountable agent investigates, plans, proves, changes, and audits the work.

2/5
A reasoning arc, not six agent handoffs

Each phase produces evidence for the next. Ownership stays continuous while independent controls remain outside the agent's self-assessment.

1
Intent

Understand

Restate the outcome, constraints, and acceptance conditions.

2
Evidence

Investigate

Read the relevant system before proposing a change.

3
Boundary

Plan

Declare the change surface, risks, and proof strategy.

4
Proof first

Test

Make expected behavior executable where the work allows it.

5
Change

Implement

Make the smallest coherent change inside the declared scope.

6
Challenge

Self-audit

Test the claim, record limitations, and prepare a clean handoff.

What continuity protects

Design intent, test reasoning, local context, and responsibility for the final claim.

What continuity does not replace

Deterministic checks, independent verification, cost boundaries, or human judgment.

Proof is not one undifferentiated gate

The factory classifies checks by consequence so rigor increases trust without turning every signal into critical-path ceremony.

Operations and Human Judgment

Automation earns trust by showing its work

State, evidence, cost, failures, and next actions stay visible so a person can intervene without reconstructing the run.

4/5

Memory and Continuous Improvement

Every run can improve the next

Learning compounds only when it is verified, traceable, measured, and kept outside the critical delivery path whenever possible.

5/5
Learning follows evidence

The factory records what happened, preserves provenance, checks remembered claims against current reality, and tests proposed improvements before promotion.

Observe

Outcome signals

Compare intended and actual results, proof quality, cost, recovery, and rework.

->
Remember

Verified memory

->
