# Study Guides

The main book is organized for uninterrupted practitioner reading. This directory preserves its complete student and self-study apparatus:

- measurable learning objectives;
- key terms;
- review questions;
- discussion questions;
- all 91 exercises;
- the deliverable and assessment criteria for every exercise.

Each chapter file stands on its own and points back to the corresponding chapter. The design-study exercises appear in `appendix-d-study-guide.md`.

## For Instructors

These files intentionally contain no solutions or answer keys. The verified-instructor package contains worked solutions, grading rubrics, quiz banks, lesson plans, and classroom notes. This separation lets practitioners move directly through the book while preserving a complete adoption-ready academic package.
