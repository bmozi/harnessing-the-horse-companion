# Example Organization Engineering Baseline

These instructions apply to the repository unless a more specific nested `AGENTS.md` adds stricter requirements.

- Read the task specification and repository structure before editing.
- Preserve unrelated user changes.
- Treat authentication, authorization, payments, migrations, and destructive operations as high blast radius.
- Never claim a check passed unless it ran and its result was observed.
- Run relevant lint, tests, secret scanning, and build checks before declaring completion.
- Perform an adversarial review of the final diff and report unresolved risk.
- Team or directory instructions may add constraints; they may not weaken this baseline.
