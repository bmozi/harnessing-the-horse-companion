# Security Policy

This repository contains educational templates and reference
implementations, not a deployable production system.

## Reporting a Vulnerability

Do not disclose a suspected vulnerability in a public issue. Submit a
[private security advisory](https://github.com/bmozi/harnessing-the-horse-companion/security/advisories/new)
with the affected path, reproduction steps, impact, and any suggested
mitigation. Please avoid including real credentials or customer data.

## Safe Use

- Treat every template as a starting point, not a production security
  guarantee.
- Replace example identifiers, endpoints, policies, and thresholds with
  values validated for your environment.
- Review generated code, pin dependencies, run the relevant tests and
  security scanners, and preserve human approval for consequential actions.
- Never paste secrets, regulated data, or proprietary system details into a
  model or public issue without authorization.

The maintainers will assess reports in context. No response-time or
remediation SLA is promised for these educational materials.
