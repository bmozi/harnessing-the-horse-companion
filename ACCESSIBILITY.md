# Accessibility

The v2.1.2 reader documents are distributed as both editable Word files and
tagged PDFs. The sources use real headings, logical reading order, repeated
table-header rows, meaningful link text, document metadata, page numbers, and
equivalent text for informative images. The five teaching panels include both
embedded alt text and visible descriptions so the central lesson does not
depend on vision or PDF extraction behavior.

## Known limits

- Accessibility depends partly on the reader application and assistive
  technology. A tagged PDF is not proof that every reading environment will
  interpret every structure identically.
- The teaching-panel images contain small visual text for sighted presentation.
  The visible description above each image carries the same governing lesson,
  but does not transcribe every decorative label.
- Color is not the only carrier of meaning in the source documents; labels and
  prose identify categories and outcomes.

Please report a barrier through the
[accessibility issue form](https://github.com/bmozi/harnessing-the-horse-companion/issues/new?template=accessibility.yml).
Include the document, page or section, device, reader application, assistive
technology if any, and the task you could not complete.
