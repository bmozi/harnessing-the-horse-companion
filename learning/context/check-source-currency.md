# Lesson 3: Check source authority and currency

Resolve conflicting or stale context before using it to choose a change.

## Relevant information can still be wrong for this task

A retrieved note may match your question while describing an old version, another service, or an unapproved proposal. Relevance helps find a candidate source; it does not make that source authoritative.

In this constructed exercise, an old note says the export includes an account identifier. The maintained consumer contract prohibits that field for the current audience. Adding the identifier because the note is easy to retrieve would cross the intended boundary.

## Compare your work

A good record separates what the source says from why it may govern this decision. Keep an old proposal identifiable as an old proposal. Do not quietly promote it into a project rule because it was repeated in a recent chat.

1. Follow the note because retrieval ranked it first.

3. Merge the two rules into a plausible compromise without recording it.
4. Ask the same model to repeat the note more confidently.
