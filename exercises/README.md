# Exercises

Hands-on practice material for *Harnessing the Horse*, suitable for
self-study or classroom use.

> These artifacts are companion materials for *Harnessing the Horse*.
> The book provides the design rationale, failure modes, and case-study
> context that make these exercises generative rather than rote.

The full instructor package (solutions, discussion prompts, grading
rubrics, sample exams) is distributed separately to verified
instructors by the author. What's here is the **student-facing** half:
problem statements, frameworks, and starter material.

## How to attempt

1. Read the related chapter(s) before starting.
2. Work the exercise in your own fork of this repo.
3. Compare your approach against the discussion in the chapter and
   the self-check criteria. The point is the *process*, not matching
   a reference solution.

## For instructors

If you're teaching with the book, the instructor package — with
solutions, grading rubrics, discussion prompts, and sample exam
questions — is available separately from the author.

If you're configuring a course, the Academic Supplement to
*Harnessing the Horse* provides three reference course
configurations:

- **Configuration A** — One-Semester Senior Elective (15 weeks)
- **Configuration B** — Two-Quarter Graduate Sequence
- **Configuration C** — Executive Education / Professional
  Certificate (5 days intensive)

## Coverage note

This directory contains the reusable student-facing exercises and
self-study frameworks that travel well outside the book: maturity
assessment, case-study analysis, case-study walkthroughs, expertise
traps, quarterly calibration, and the 30-day transformation roadmap.
Chapter-specific exercises remain in the book so readers encounter
them in sequence with the surrounding explanation.
