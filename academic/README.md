# Academic Adoption Resources

This directory carries curriculum-facing material intentionally kept out of the focused practitioner edition.

- `competency-curriculum-map.md` maps the book's standards to competencies, evidence artifacts, assessments, and curriculum frameworks.
- `../study-guides/` contains the formal objectives, key terms, questions, exercises, deliverables, and assessment criteria.

Instructor-only answer keys and grading rubrics are distributed separately so public student materials do not expose solutions.
