# Editable Accessible Downloads

These Word editions are the semantic sources for the tagged PDFs in
[`../pdf/`](../pdf/). They provide real headings, reading-order structure,
table headers where applicable, descriptive text for visuals, and editable
formats for readers who need to restyle or enlarge the material.

| File | Purpose |
| --- | --- |
| `Harnessing-the-Horse-Reader-Quick-Start-v2.1.2.docx` | Editable six-page reader orientation |
| `Harnessing-the-Horse-Software-Factory-Teaching-Panels-v2.1.2.docx` | Editable five-panel teaching set with alt text and equivalent descriptions |

Rebuild both files using the scripts documented in
[`release-assets/README.md`](../../release-assets/README.md).
